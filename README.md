# LAB 03 - Introduction to NodeJS and GitHub Flow
IT23594586 - Hanaan M.F.A.S


## **Overview**

This lab focuses on learning the basics of **Node.js**, **Git**, and **GitHub flow**.  
Students are introduced to basic Node.js commands, creating a Git repository, and working with GitHub to **commit, push, pull**, and **merge branches**.

---

## **Repository Structure**

- `app.js` – Main application file with console log message.
- `readFile.js` – Demonstrates reading a file using Node.js `fs` module.
- `writeFile.js` – Demonstrates writing to a file using Node.js `fs` module.
- `webServer.js` – Node.js HTTP web server.
- `httpRequest.js` – Making HTTP requests using Node.js `https` module.
- `my-module.js` – Custom module used in `useModule.js`.
- `useModule.js` – Demonstrates importing and using a module.
- `promises.js` – Example of using Promises.
- `asyncAwait.js` – Example of using async/await with Promises.
- `package.json` – Node.js project configuration file.

---

## **Lab Objectives**

1. Set up a Node.js project with `npm init`.  
2. Create multiple feature branches using GitHub flow:
   - `feature/<your-name>/<feature-name>`  
3. Commit changes for individual Node.js examples.  
4. Push branches to GitHub and create **Pull Requests**.  
5. Merge branches into main and pull the latest changes.  
6. Resolve merge conflicts (if any).  
7. Collaborate with peers using GitHub as a team.

---

## **Node.js Features Covered**

1. Read files using `fs.readFile`.  
2. Write files using `fs.writeFile`.  
3. Create a simple HTTP server.  
4. Make HTTP requests with `https`.  
5. Create and use custom modules.  
6. Work with Promises.  
7. Work with async/await.

---

## **Git & GitHub Flow**

- Create a **feature branch** for each task.  
- Commit and push changes separately for each feature.  
- Open **Pull Requests** to merge features into `main`.  
- Pull changes locally after merges.  
- Resolve conflicts if they arise.  
- Collaborate with a partner by adding them as a collaborator.
